1.1. История серьёзных проблем
Пользователь лично наблюдал:
1. Полностью чёрное окно.
2. Полностью белое окно.
3. Нестабильный запуск.
4. Периодическую работу «через раз».
5. Серьёзные GUI-зависания.
6. Невозможность закрытия через крестик.
7. Необходимость завершения через Task Manager.
Предыдущая Astra обнаружила и исправляла:
- Некорректное завершение Qt event loop.
- Оставшиеся фоновые потоки после закрытия.
- Ошибку перехода STARTING → ERROR_RECOVERABLE.
- Ложноположительные packaged smoke-tests.
- Избыточную переполировку QSS.
- Проблемы сборочного smoke.
- Недостаточную диагностику ранних зависаний.
В Windows Event Log обнаруживалась запись Application Hang / AppHangB1.

Предыдущие отчёты содержали успешные серии 100 запусков исходников и установленного тестового EXE, однако точная причина исходного чёрного/белого экрана не была подтверждена.

В более поздней сессии обнаружен дополнительный UX-дефект: при отсутствии установленной модели главный экран показывал «Готово», хотя диктовка фактически была недоступна.

Не считай ни один из этих дефектов автоматически исправленным в актуальной версии.

Не доверяй прежним заявлениям о 100% готовности.
