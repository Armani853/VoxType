# Руководство пользователя VoxType

## Установка и первый запуск

Portable-версию распакуйте в обычную папку пользователя и запустите
`VoxType.exe`; администратор не нужен. Installer ставит те же файлы в
`%LOCALAPPDATA%\Programs\VoxType`. При первом запуске мастер объяснит local-first
режим, предложит микрофон, калибровку, профиль и загрузку модели.

Модель может занимать от сотен мегабайт до нескольких гигабайт. Не закрывайте
приложение до завершения атомарной загрузки. Повторный запуск не скачивает
готовую модель.

## Диктовка

1. Откройте Notepad, Word, браузер, Telegram, VS Code либо другое поле.
2. Установите текстовую каретку и нажмите `Ctrl+Alt+Space`.
3. Overlay должен показать микрофон, RU/EN, timer и уровень.
4. Говорите обычными фразами. Подтверждённый текст приходит после паузы либо
   forced chunk; provisional text не вставляется.
5. Нажмите комбинацию ещё раз. Статус «Завершаю» означает обработку хвоста; не
   завершайте процесс до «Готово».

## RU и EN

Кнопки RU/EN или `Ctrl+Alt+L` задают язык явно. Во время сессии текущий chunk
закрывается старым языком, следующий начинается новым. RU не переводит английский
и EN не переводит русский. AUTO не является основным режимом.

## Микрофон и уровень

В настройках → Аудио выберите именно input device, предпочтительно WASAPI.
Индикатор:

- «слишком тихо» — приблизьте микрофон/проверьте Windows input level;
- зелёный — нормальный уровень;
- «клиппинг» — уменьшите input gain/отодвиньте микрофон;
- неподвижный meter — вероятно выбран не тот endpoint.

Профили Raw/Normal/Noisy room меняют только локальную обработку. VoxType сам не
меняет системную громкость.

## Целевое окно

Locked target безопаснее: если вы переключились, распознавание продолжается, а
вставка ждёт возврата. Follow focus нужно включить явно; проверяйте название цели
в overlay. В собственные окна VoxType текст не вставляется.

Elevated target недоступен обычному VoxType из-за Windows UIPI. Накопленный текст
не теряется: выберите «Скопировать» и вставьте вручную.

## Безопасный clipboard

Режим safe-copy вообще не генерирует ввод: committed text копируется, а вы
нажимаете Ctrl+V. Обычная clipboard paste временно сохраняет clipboard и
восстанавливает его. Если за время paste clipboard изменило другое приложение,
VoxType сохраняет новые данные и показывает предупреждение вместо их перезаписи.

## Голосовые команды

Команды пунктуации выключены по умолчанию. После включения поддерживаются «точка»,
«запятая», «новая строка», «новый абзац» и перечисленные в настройках English
аналоги. Команды не запускают программы, shell и файлы.

## История и восстановление

История показывает локальные сессии, предупреждения и suspected fragments. После
сбоя следующая загрузка находит незавершённую сессию и даёт скопировать committed
text; spool не удаляется до успешной обработки/отказа пользователя.

## Удаление данных

Настройки → Приватность → «Удалить все локальные данные» очищает history/audio
после подтверждения. Модели удаляются отдельно в разделе «Модель». Полные пути
видны по кнопке «Открыть папку данных»; перед ручным удалением завершите VoxType.
