# Приватность

VoxType обрабатывает голос локально. Нет облачного STT, telemetry, analytics,
автоматической отправки crash reports, входящего порта и локального HTTP-сервера.

Сеть используется только при явной загрузке выбранной model snapshot. После
полной установки inference открывает локальные файлы; аудио и текст не передаются.

Локально могут храниться:

- settings JSON;
- rotating technical logs без transcript/PCM;
- SQLite session history с committed text, если history включена;
- temporary PCM spool до успешной обработки/recovery;
- исходное аудио только если пользователь включил его сохранение;
- model cache.

Точные каталоги определяются `platformdirs` и показываются в Diagnostics.
Удаление истории не удаляет модели; «Удалить все данные» и «Удалить модель» —
раздельные явные действия. Перед ручным удалением завершите приложение.

Clipboard временно используется для paste. Snapshot восстанавливается только
если это не уничтожит более новое содержимое clipboard. Safe-copy оставляет
текст в clipboard по явному выбору пользователя.
