# Речевые сценарии VoxType

`references.json` содержит десять эталонов. Скрипт `generate.ps1` создаёт локальные WAV PCM16, 16 кГц, mono и записывает фактическую длительность, голос и темп в `build/real-world-audio/manifest.json`. Требуются русская Irina и английская Zira из Windows SAPI. Скрипт проверяет допуск ±10% по длительности записи. Сигнал синтетический.

После генерации можно проверить тракт захвата из корня репозитория:

```powershell
.\.venv\Scripts\python.exe -m tools.run_capture_acceptance build\real-world-audio build\qa-release-7f9638a\data\models build\qa-capture-next --input-device 19 --output-device 11 --case RU-05 --case EN-05
```

Укажите существующий каталог с локальными моделями, новый каталог профиля и фактические индексы входа и выхода. На проверенном ПК 19 — Realtek Stereo Mix, 11 — динамики Realtek. Выполняйте проверку при отсутствии другого воспроизводимого звука. Без `--case` запускаются все десять сценариев последовательно в реальном времени. Результаты записываются в `capture-results.json` внутри профиля.

WER и CER вычисляются после нормализации регистра и замены «ё» на «е». Дефисы и апострофы внутри слов сохраняются, прочая пунктуация исключается. Для CER слова соединяются без пробелов. Проверка проходит через штатный захват, VAD и ASR из исходников. Приёмка установленного EXE, хоткеев, интерфейса и вставки выполняется отдельно.
