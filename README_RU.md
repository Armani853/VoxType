# VoxType

VoxType — локальное приложение для продолжительной диктовки на Windows 11.
Оно записывает микрофон ограниченными блоками, выделяет речь, распознаёт её
faster-whisper и безопасно доставляет только подтверждённые фрагменты в
зафиксированное текстовое окно. Облачный Speech-to-Text, телеметрия и аккаунт не
используются.

## Быстрый запуск из исходников

Требуются Windows 11 x64, Python 3.12 x64 и не менее 2 ГиБ свободного места без
модели (для больших моделей требуется заметно больше).

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\bootstrap.ps1
.\scripts\run.ps1
```

`bootstrap.ps1` создаёт локальную `.venv` и устанавливает версии из
`requirements.lock`. Модели хранятся в пользовательской системной папке данных,
а не в репозитории.

## Первый запуск

1. Выберите микрофон WASAPI и проверьте уровень.
2. Оставьте профиль «Баланс» — это локальный профиль первого запуска.
3. Разрешите загрузить выбранную модель. Это единственная обязательная сетевая
   операция; после полной загрузки диктовка работает локально.
4. Откройте тестовое поле мастера и проверьте RU/EN.
5. Запомните основную комбинацию `Ctrl+Alt+Space`.

## Использование

1. Поставьте текстовую каретку в нужное поле.
2. Нажмите `Ctrl+Alt+Space` и говорите.
3. `Ctrl+Alt+L` переключает RU/EN с завершением текущего чанка.
4. `Ctrl+Alt+P` ставит активную сессию на паузу.
5. Повторное `Ctrl+Alt+Space` завершает захват и дожидается хвоста очереди.

По умолчанию действует Locked target: VoxType запоминает окно при старте и не
переносит задержавшийся текст в случайно активированное окно. Если цель неактивна,
текст остаётся в локальной FIFO-очереди. Для окна, запущенного от администратора,
используйте безопасное копирование в clipboard.

## Профили моделей

- «Быстро» — малая задержка и минимальная нагрузка.
- «Баланс» — `small/int8` и один выборочный повтор на
  `large-v3-turbo`, только если guard пометил сегмент сомнительным.
- «Максимальная точность» — `large-v3-turbo/int8` на каждом сегменте; на этом
  мобильном CPU может существенно накапливать backlog.

Production-параметры зафиксированы: raw preprocessing, предпочтительный чанк
15 секунд, максимум 25 секунд, overlap 0,8 секунды и контекст не более
30 завершённых слов. Язык задаётся явно RU/EN; после длинной паузы или смены
языка контекст сбрасывается. Vulkan backend не используется.

Название профиля не гарантирует скорость: VoxType измеряет
`RTF = inference_time / audio_duration`. Для непрерывной работы нужен RTF < 1,
желательно ≤ 0,7.

## Данные и ограничения

- История текста хранится локально и отключается в настройках.
- Сохранение исходного аудио выключено по умолчанию.
- Overlay показывает `LOCAL`: production-профили не отправляют аудио в сеть.
- Без цифрового сертификата Windows SmartScreen может показать предупреждение.
- UIPI не позволяет обычному процессу вводить текст в elevated-приложение.
- Whisper-модель не включена в portable ZIP и загружается отдельно.
- Русская контрольная расшифровка является pseudo-reference от другого
  Whisper-сервиса; измеренные 28,402% pseudo-WER не подтверждают качество 90–95%.
